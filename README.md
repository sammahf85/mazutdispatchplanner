# Mazut Dispatch Planner

Plans mazut deliveries: groups nearby customer orders, fills each tanker to its capacity, schedules extra trips when orders exceed the fleet, and shows the drivers' live locations.

**MazutDispatch.html** is the program. Download it and double-click it to open it in Chrome, Edge or Firefox.

**driver-setup-page/index.html** is the drivers' phone setup page (live location with OwnTracks), published at https://sammahf85.github.io/mazutdispatchplanner/driver-setup-page/

Orders, customers, trucks and the tracking secret key are saved only in the browser on your own computer, never in these files. Use Settings, Save backup file to move them to another computer.
